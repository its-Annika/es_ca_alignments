This repository contains forced alignments for two audio corpora:

- The Spanish partition of [Multilingual LibriSpeech](https://www.openslr.org/94/)
- [Crowdsourced high-quality Catalan speech data set](https://www.openslr.org/69/)

These alignments were created for, and used in, the project [Small Neural Models as Models of Cross-Linguistic Speech Perception](https://github.com/its-Annika/neural-speech-perception).
